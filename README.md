# Data Analysis Portfolio

A collection of end-to-end data analysis projects covering public health, sales performance, credit risk, and business intelligence. Each project demonstrates a complete analytics workflow, from raw data ingestion to interactive dashboards and business insights.

## Projects

### 1. COVID-19 Global Analysis with SQL and Power BI

An end-to-end analysis of global COVID-19 data from the World Health Organization (WHO), covering data ingestion with Python, dimensional modeling in PostgreSQL, advanced SQL queries with CTEs and window functions, and an interactive Power BI dashboard with DAX measures.

**Key skills:** SQL, Power BI, DAX, Python, dimensional modeling, time series analysis, data storytelling.

**Folder:** `data_analysis_epidem/`

### 2. Superstore Sales Performance and Profitability Analysis

An end-to-end analysis of retail sales data focused on profitability, margins, and the impact of discounts. Uses SQL, Power BI, DAX, Power Query and Python to answer business questions such as which categories are most profitable, which region has the highest margin, and how discounts affect profitability.

**Key skills:** SQL, Power BI, DAX, Power Query, Python, star schema modeling, business intelligence, profitability analysis.

**Folder:** `data_analysis_finance/`

### 3. Credit Risk Analytics with Modern Data Stack

An end-to-end data pipeline analyzing credit default risk using a modern data stack. Covers data ingestion with Python, transformation with dbt (staging, intermediate, marts), orchestration with Apache Airflow, and (in progress) processing with Databricks and visualization with Power BI.

**Key skills:** SQL, PostgreSQL, dbt, Apache Airflow, Python, dimensional modeling, data orchestration, ETL pipelines.

**Folder:** `data_analysis_risk/`

## Common Stack Across Projects

- SQL (PostgreSQL) for data modeling and advanced queries
- Power BI for interactive dashboards
- DAX for calculated measures
- Power Query for data transformation
- Python (pandas, sqlalchemy) for data ingestion and automation
- dbt for data transformation (credit risk project)
- Apache Airflow for pipeline orchestration (credit risk project)
- Git for version control
